# AtOnce

AtOnce is a free-form workflow canvas for QGIS. Connect source layers to operations and outputs, track lineage, and refresh only the branches you choose.

Version: **v0.1.10**

Capabilities include vector filtering, joins, merges, field and spatial operations, raster conversion, selective updates, and delivery to GeoJSON, Shapefile, KML, KMZ, GeoPackage, and GeoTIFF.

AtOnce supports QGIS **3.28 through 3.99**.

## Installation

1. Download `dist/atonce-0.1.10.zip`.
2. In QGIS, open **Plugins → Manage and Install Plugins…**.
3. Choose **Install from ZIP**, select the downloaded archive, and restart QGIS if prompted.
